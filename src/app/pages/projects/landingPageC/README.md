# Landing Elaborada — Vértice

Demo del paquete **Landing Page Elaborada** (S/700–S/1.000). Vive dentro de TechnologicalCode, no es un segundo `ng new`.

## Cómo verla

Desde la raíz del repo:

```bash
npm start
```

Abre [http://localhost:4200/projects/landing-elaborada](http://localhost:4200/projects/landing-elaborada).

## Qué incluye

- Secciones en componentes standalone (`lpc-hero`, `lpc-about`, etc.).
- GSAP + ScrollTrigger (solo ese plugin) para entradas y stagger.
- Animación CSS al entrar el bloque (testimonios y confirmación del formulario).
- Reactive Forms con validación; el envío es un mock (timeout).
- Galería con lightbox propio y WhatsApp flotante.

Los tiempos de GSAP están comentados en cada componente.
